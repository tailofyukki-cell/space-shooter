# ASTRAL BLOOM — ボム演出・第2ステージ追加報告

## 成果

第1ステージのみだった横スクロール弾幕シューティングを、ボムの画面内演出を持つ2ステージ構成へ拡張した。ボムは残数だけが減る見えにくい機能から、名称・星環・拡張波紋・閃光・敵弾キャンセル数・通常敵浄化数・持続ゲージを示す **AETHER BREAK** へ変更している。

第2ステージ **「月虹の導水路」** をステージ選択に追加した。月光の水晶導水路背景、既存通常敵の新しい配置、琥珀プリズム弾・水門針弾、2フェーズボス〈ルーメン・アーコン〉、第2ステージ専用のアナウンスをゲームパックで定義している。

## ボム：AETHER BREAK

| 要素 | 実装内容 |
| --- | --- |
| 視覚演出 | 白青の中心閃光、3重の拡張星環、`AETHER BREAK` 表記、キャンセル数・浄化数の表示。 |
| HUD | 左下に持続ゲージを表示し、右HUDの残ボム数も即時に減少。 |
| 効果 | キャンセル可能な敵弾を全消去し、通常敵を浄化、ボスへ34ダメージを与える。 |
| 無敵 | ボム持続1.35秒に加えて0.25秒の安全余裕を確保。発動中は自機を点滅消去しない。 |
| 再利用性 | `bomb` イベントが位置・持続・キャンセル数・浄化数を渡すため、作品別の名称・色・演出へ差し替え可能。 |

ブラウザ確認では、第2ステージ中のXキー入力で星環、`CANCEL 019 / PURIFY 01`、持続ゲージ、残ボム数の更新を同時に確認した。

## 第2ステージ

| 項目 | 内容 |
| --- | --- |
| ID | `stage_moonrain_02` |
| 表示名 | `STAGE 02 — 月虹の導水路` / `Moonrain Conduit` |
| 背景 | 月光・星水・水晶水門を持つ横長背景。中央に回避用の低密度空間を確保。 |
| 通常敵 | 花粉偵察機、花弁精霊、結晶ガーデナーを高速・連携型に再配置。 |
| ボス | ルーメン・アーコン。月虹の水門／星水の審判の2フェーズ。 |
| 新敵弾 | 琥珀の `lunar_prism`、青白い `aqua_gate`。既存の危険弾と色で区別。 |
| クリア | ボス撃破。 |

背景とボススプライトはマニフェストの `visuals.backgrounds` と `visuals.sprites` からロードする。第3ステージ以降は、ステージJSON、背景参照、必要な敵・弾幕を同じ構成で追加できる。
