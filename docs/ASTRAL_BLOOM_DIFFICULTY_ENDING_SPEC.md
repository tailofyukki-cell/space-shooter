# ASTRAL BLOOM — 難易度・エンディング仕様

## 目的

本仕様は、横スクロール弾幕シューティングの体験難度を **Easy / Normal / Hard** の3段階で提供し、最終ステージ撃破時にキャンペーン完結を示すエンディングへ遷移させるためのものである。難易度によってステージJSONを複製せず、ゲームパックの数値補正と実行時の共通処理で差異を作る。

## 難易度プリセット

| 難易度 | 想定プレイヤー | 残機 | ボム | 敵耐久 | 敵弾速度 | 弾幕密度 | 表示色 |
| --- | --- | ---: | ---: | ---: | ---: | ---: | --- |
| Easy | 弾幕シューティング初心者 | 5 | 4 | 72% | 82% | 72% | 青緑 |
| Normal | 標準的な初回クリア | 3 | 3 | 100% | 100% | 100% | 青紫 |
| Hard | パターン把握後の挑戦 | 2 | 2 | 135% | 120% | 130% | 琥珀 |

敵耐久補正は通常敵とボスの各フェーズHPへ適用する。弾幕密度補正は扇状・環状・螺旋パターンの発射弾数およびrepeat数を整数化して適用し、常に最低1発を保証する。弾速補正は敵弾の速度ベクトルへ共通適用する。

## UIと保存

タイトル画面の開始操作は難易度選択画面へ進み、Easy / Normal / Hardのいずれかを選んでから入口ステージを開始する。ステージ選択から始める場合も、選択済み難易度を表示し、難易度選択へ戻れるようにする。直近の選択はローカル設定に保存する。

HUDには現在の難易度を簡潔に表示する。結果画面ではステージクリア／失敗と最終スコアに加え、達成難易度を表示する。

## キャンペーンとエンディング

マニフェストのステージ一覧をキャンペーン順序とする。第1ステージをクリアした場合は通常のステージクリア結果へ遷移する。最終ステージ（現時点では第2ステージ）をクリアした場合は、結果画面に置き換えてエンディング画面を表示する。

エンディングでは、浄化された月虹の導水路、カデンツァ7、完了メッセージ、クリア難易度、スコアを表示する。本文は難易度共通のトゥルーエンドとし、Hardでは追加の「高難度達成」メッセージを表示する。操作はタイトルへ戻る、同じ難易度で再出撃する、難易度選択へ戻るの3つとする。

## データ契約

`manifest.json` に以下を追加する。

```json
{
  "difficultyPresets": {
    "easy": { "label": "EASY", "playerLives": 5, "playerBombs": 4, "enemyHpMultiplier": 0.72, "bulletSpeedMultiplier": 0.82, "bulletDensityMultiplier": 0.72 },
    "normal": { "label": "NORMAL", "playerLives": 3, "playerBombs": 3, "enemyHpMultiplier": 1, "bulletSpeedMultiplier": 1, "bulletDensityMultiplier": 1 },
    "hard": { "label": "HARD", "playerLives": 2, "playerBombs": 2, "enemyHpMultiplier": 1.35, "bulletSpeedMultiplier": 1.2, "bulletDensityMultiplier": 1.3 }
  },
  "campaign": { "endingAfterFinalStage": true }
}
```

ゲームワールドは `setDifficulty(id)` と `difficulty` を持ち、プレイヤー初期値、敵定義コピー、弾幕生成に補正を適用する。画面フローは最終ステージの `stageClear` を受けてエンディングに遷移する。
