# 横スクロール弾幕シューティングへの再構成仕様

## 判断

ASTRAL BLOOMの現行プロトタイプは、製品化時の「弾幕シューティング」という目標を解釈して縦スクロールへ変更している。しかし元のMVPは、**自機が画面左側に位置し、敵と背景が右から左へ流れる横スクロール**として実装されていた。以後の正規仕様は、この横スクロールを維持する。

縦型プロトタイプは削除しない。ボスフェーズ、JSONゲームパック、設定保存、音声フック、Electron配布、テストなど、軸に依存しない基盤機能を参照実装として残す。ただし、ユーザーが遊ぶ標準版は横スクロール用ランタイムとする。

## 維持する元MVPの体験

| 項目 | 横スクロール仕様 |
| --- | --- |
| 自機位置 | プレイフィールド左側を基本位置とする。 |
| 背景 | 星・背景レイヤーが右から左へ流れる。 |
| 敵の登場 | 右側から現れ、左方向へ接近する。 |
| 自機ショット | 右方向へ発射する。 |
| 敵弾 | 左方向、または自機を狙う角度で発射する。 |
| 操作 | WASD／矢印で上下左右、SpaceまたはZでショット、Shiftで低速、Xでボム。 |
| ステージ | 一定時間のウェーブ後にボス戦を開始し、ボス撃破でクリアする。 |

## 再利用する製品基盤

| 区分 | 引き継ぐ機能 |
| --- | --- |
| データ | `content-packs/<作品ID>/`、マニフェスト、敵・弾・弾幕・ステージ・文言のJSON分離。 |
| 弾幕 | 扇状、円形、狙い撃ち、螺旋のパターン定義。角度の基準を横スクロール用に調整する。 |
| 敵 | 直進、正弦波、停滞、ボスフェーズ、HP、スコア。 |
| 製品機能 | 設定保存、音量、フルスクリーン、ステージ選択、Electron配布。 |
| 品質 | スモークテスト、ゲームパックJSON検証、試遊テスト。 |

## ASTRAL BLOOM第1ステージの横スクロール版

第1ステージ「硝子雨の庭園」は、画面右方に広がる軌道温室へ侵入する構成へ変更する。自機〈カデンツァ7〉は左側から右へ向けて進み、花粉偵察機、花弁精霊、結晶ガーデナー、庭園制御核〈フローラ・オルビス〉が右側から現れる。

危険弾は右から左へ流れる花弁・種子・蔓として設計する。弾幕の密度は、横方向へ長く避け続けるのではなく、上下回避と前後移動の判断が必要になる配置を基本とする。自弾は右方向へ発射されるため、自機の左右位置がリスクと攻撃距離のトレードオフになる。

## 実装方針

縦型専用の `GameWorld`、`Player`、`Enemy`、`PatternRunner`、`Renderer` を直接破壊せず、横スクロール用のランタイムとして切り出す。正規アプリケーションの読み込み先を横スクロールランタイムへ切り替え、既存の縦型ランタイムは `src/vertical-reference/` へ隔離する。ゲームパック側は同じJSON構成を使いながら、移動ベクトル、発射角度、ステージ座標を横スクロール用に変更する。
