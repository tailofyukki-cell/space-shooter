# ASTRAL BLOOM — ボム演出・第2ステージ追加仕様

## ボム：AETHER BREAK

現在のボムは、敵弾消去・SE・短い無敵だけを持ち、弾幕の中で発動結果を認識しづらい。以後はボムを **AETHER BREAK** と呼び、画面内に半透明の星環、3重の拡張リング、白青の閃光、弾消去粒子、持続時間バーを表示する。発動時には敵弾の消去数を計測して演出へ渡し、消去された敵弾の一部から吸い込まれる花弁状パーティクルを生成する。

| 項目 | 仕様 |
| --- | --- |
| 持続時間 | 1.35秒。自機無敵は1.6秒以上を保証する。 |
| 視覚演出 | 中心閃光、星環、3重波紋、画面内の `AETHER BREAK` 表示、敵弾消去粒子。 |
| ゲーム効果 | キャンセル可能な敵弾を全消去し、ボス以外の敵へ小ダメージを与える。 |
| HUD | 残弾表示に加え、発動中の名称・持続ゲージ・キャンセル数を表示する。 |
| 再利用性 | `bomb` イベントに位置・持続・消去数を渡し、作品別の色・名称・SEをデータと描画側から差し替えられる。 |

## 第2ステージ：月虹の導水路

> **Stage 02 — 月虹の導水路**
>
> 硝子雨の庭園の地下で、星の水を循環させる巨大な導水リングが暴走している。自機カデンツァ7は、反射する水晶水路を右へ進み、月光の結晶を制御する門衛機〈ルーメン・アーコン〉を停止させる。

第2ステージは第1ステージの横スクロール契約を維持し、`manifest.stages` へ独立したJSONを追加する。既存の通常敵を高速・連携型として再配置し、新ボスと新弾幕によって難易度を一段階引き上げる。

| 区間 | 時間目安 | 内容 |
| --- | ---: | --- |
| 導水路侵入 | 0〜18秒 | 花粉偵察機の高速編隊。ボム導入用の緩い扇状弾。 |
| 鏡面水門 | 18〜40秒 | 花弁精霊と結晶ガーデナーの連携。上下レーンの誘導弾。 |
| 月虹圧力室 | 40〜56秒 | 高密度の琥珀弾・菱形弾。ボムを使う余地を作る。 |
| ボス戦 | 56秒〜 | ルーメン・アーコンの2フェーズ。回転環と水門レーザーを模した弾幕。 |

## アセット方針

第2ステージには「月光を含む水晶導水路」の横長背景と、銀白・群青・琥珀色の新ボススプライトを制作する。通常敵は第1ステージの刷新済みスプライトを再利用し、ステージ2専用のアニメーション・色差分・BGMは後続の音響／演出工程で追加する。ステージデータ、弾幕、背景・ボス画像参照を分離し、以後の第3ステージ以降も同じ形式で追加する。
