# ASTRAL BLOOM — 敵アート再設計仕様

## 改善方針

現行の敵は簡略図形に見え、ボスも単純な発光菱形であるため、弾幕の中心にいても「何と戦っているか」が伝わりにくい。新アートでは、軌道温室を侵食した**機械花・結晶・制御核**という統一テーマを、左向きの輪郭、実体感のある装甲、ひとつの発光コア、花弁・環・結晶の副形状で表現する。

危険弾がマゼンタと珊瑚色であるため、敵本体の主色は黒紫・白銀・青緑・深緑を使い、マゼンタは小さなコア発光に限定する。敵と弾の判別を最優先し、半透明の大きな花弁、白一色の輪郭、背景と同系色の薄い青い塊は避ける。

## 生成・統合条件

各スプライトは**単体の透明PNG**として生成し、背景・地面・影・文字・弾・UIを含めない。対象を中央に十分な余白を取って収め、切断された花弁・翼・リングを作らない。すべて左向きの横スクロール用3/4側面とし、ゲーム内では右側から進入して左へ攻撃する。

生成後は背景を除去し、実ピクセルの描画領域を保ったままゲーム用PNGへ整形する。マニフェストの論理キーは変更せず、現在の画像ファイルを新スプライトで置き換える。画像未読込時の図形フォールバックは残す。
