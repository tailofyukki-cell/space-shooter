# 視覚確認ログ（2026-08-17）

## 起動確認

ローカル開発サーバー上で `DANMAKU ENGINE DEMO` を起動した。タイトル画面には、作品名、基盤の説明、ゲーム開始ボタン、および移動・低速・ショット・ボム・ポーズの操作説明が表示された。ゲームパック読込エラーは表示されず、`game-data/` のマニフェストおよびテキスト定義が正常に反映されている。

## プレイ開始確認

開始ボタンを選択すると、タイトル画面が閉じ、540×720の縦長プレイフィールド、自機、星空背景、スコア、残機、ボム、グレイズのHUDが表示された。初期表示では残機3、ボム3、スコア0であり、自機はフィールド下部中央に配置されている。これにより、HTML、JSONゲームパック、ES Modules、レンダラー、ゲームワールドの初期結線が正常に動作していることを確認した。

## 次の確認項目

敵のタイムライン出現、弾幕発射、ショットによる敵撃破、被弾・グレイズ・ボム、ボス出現、結果画面、ポーズ、設定保存、音声再生を確認する。

## ゲームオーバーとリトライ確認

敵弾に接触した状態で放置すると、残機が尽きたあとに「MISSION FAILED / GAME OVER」と最終スコアを表示する結果画面へ遷移した。結果画面の「もう一度遊ぶ」を選択すると、スコア0、残機3、ボム3の初期状態でプレイフィールドに復帰した。従って、被弾、残機消費、ゲームオーバー、リトライの主要フローが実装されていることを確認した。

## 追加検証

プレイ中に敵弾の密度が上がるとゲームオーバー画面へ遷移することを再確認した。ブラウザ試遊ではショットを継続入力する自動化は行わず、敵出現・弾幕・自弾・ボムの各コア機能は別途Node.jsのスモークテストで検証した。スモークテストは、ステージタイムラインによる敵出現、自弾生成、JSON弾幕による敵弾生成、ボムによる敵弾消去と残数減少をすべて正常として完了している。

## 設定画面確認

タイトル画面から「設定」を選択すると、BGM音量（既定80%）、SE音量（既定90%）、フルスクリーン表示、および戻る操作を備えた設定画面が表示された。設定値はゲームIDをキーとしてローカル保存する実装であり、作品ごとの設定が他作品と衝突しない構成になっている。

## 設定画面からの復帰確認

設定画面の「戻る」を選択すると、タイトル画面へ正しく復帰した。タイトル画面、設定画面、プレイ画面は重複表示されず、画面遷移時に不要なオーバーレイが隠れることを確認した。

## ステージ選択確認

最新版を読み直すと、タイトル画面に「ステージ選択」導線が表示された。選択画面では `game-data/stages/stage_demo_01.json` に定義した「基盤検証ステージ」と副題「星屑のテストフィールド」が一覧項目として生成され、ステージ定義を追加することで選択肢を増やせる構成であることを確認した。
