# ASTRAL BLOOM — ステージ識別HUD改善報告

## 背景と解決方針

従来のプレイ画面は難易度、スコア、残機、ボムを表示していた一方、現在プレイしているステージを常時示していなかった。4ステージのキャンペーンでは、プレイヤーが開始直後、通常戦、中ボス戦、最終ボス戦のいずれでも現在地を確認できることが必要である。

この改善では、プレイフィールド左上に固定ミッションHUDを追加し、ステージ名・英語副題・進行バー・戦闘状態を表示した。開始、ボス警告、フェーズ遷移の通知にもステージ名を併記した。

## 実装内容

| 表示箇所 | 内容 | 表示条件 |
| --- | --- | --- |
| フィールド左上 | `MISSION PROGRESS`、ステージ和名、英語副題、進行バー | 常時 |
| 固定HUDの状態 | `MISSION PROGRESS`、`SUB BOSS ENCOUNTER`、`FINAL ENCOUNTER` | 通常戦、中ボス戦、最終ボス戦で自動切替 |
| 画面中央上部 | `MISSION START // ステージ名 — 副題` | ステージ開始時 |
| 画面中央上部 | ステージ名を含む中ボス・最終ボス警告 | 中ボス・最終ボス出現時 |
| 右HUD | 難易度、スコア、残機、ボム、グレイズ | 従来どおり常時 |

進行バーは通常戦で最終ボス出現イベントまでの進行を示し、最終ボス戦では100%として表示する。中ボス戦は専用の金色状態表示へ切り替わる。ステージHUDはCanvas上のプレイフィールド内に配置され、背景・敵弾・ボスゲージとは重ならないようにしている。

## 検証結果

レンダラー回帰テストで、現在ステージ名、副題、通常進行状態が描画されることを自動検証した。全ステージのスモーク、ステージパック、中ボス、難易度、エンディング、設定、音声管理の回帰も成功した。

ブラウザでは第4ステージをNormalで開始し、`MISSION PROGRESS`、`STAGE 04 — アストラル・ブルーム中枢`、`Astral Core`、進行バーと、導入バナーが同時に表示されることを確認した。

## 試遊方法

指定ローカルフォルダの `PLAY_ASTRAL_BLOOM.bat` を実行するか、ローカルサーバー起動済みの場合は `http://127.0.0.1:4173/` を開く。更新を反映する際は `Ctrl + F5` を使用する。タイトルの「キャンペーンへ進入」または「ステージ選択」から任意ステージを開始できる。
