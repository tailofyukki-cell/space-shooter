# ASTRAL BLOOM — 第1ステージ初期試遊記録

## 対象

第1ステージ「硝子雨の庭園」の導入からボス警告直前までを対象に、ショット継続、敵弾の局所密度を避ける横移動、12秒間隔のボム使用を行う固定デルタタイムの自動試遊を実施した。

## 結果

| 指標 | 結果 | 判定 |
| --- | ---: | --- |
| 試遊時間 | 52秒 | 合格 |
| ゲームオーバー | なし | 合格 |
| 残機 | 1 | 継続調整対象 |
| 最大同時敵弾数 | 43 | 合格 |
| 獲得スコア | 1,820 | 通常敵撃破を確認 |
| 結晶ガーデナー出現 | 確認 | 合格 |

## 調整内容

初期版では、通常速度の往復入力による自動試遊が約19秒でゲームオーバーとなった。そこで、花粉偵察機の扇状弾を5way×5回から3way×3回へ、花弁精霊の円形弾を12way×4回から8way×3回へ抑え、弾速を下げた。結晶ガーデナーの狙い撃ちと螺旋弾も、発射周期を長くし、発射回数を減らした。

この変更後、敵弾密度の低いレーンを選択する自動試遊は52秒間生存し、最大同時敵弾数43で推移した。残機は1で終了したため、初見プレイに対してはまだ緊張感が高い。次回の実機試遊では、導入区間の被弾位置、ボムの使用感、花弁弾と背景の視認性を確認し、必要に応じて弾速または初期残機を追加調整する。
