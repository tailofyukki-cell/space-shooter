# ゲームパック制作ガイド

## 1. このガイドの目的

本ガイドは、Danmaku Engineを使って別の同人弾幕シューティング作品を作る際に、どのファイルを入れ替えればよいかを示します。通常の作品制作では、`src/core/`と`src/gameplay/`を変更せず、主に`game-data/`と`assets/`を差し替えます。

> **原則:** 「世界観とゲーム内容はデータに置き、エンジンはできるだけ共通化する。」

## 2. 新作開始時の手順

最初にリポジトリを複製し、`manifest.json`の `id`、`title`、`version` を新作専用の値へ変更します。続いて、作品の素材を `assets/` へ配置し、マニフェストの論理名から参照します。最後に、テキスト、自機、敵、弾、弾幕、ステージを順に作成します。

| 順序 | 変更する場所 | 主な内容 | 確認事項 |
|---:|---|---|---|
| 1 | `game-data/manifest.json` | 作品ID、タイトル、画面、アセット表 | IDが既存作品と重複しない |
| 2 | `assets/` | 画像、BGM、SE、フォント | 商用利用・再配布権を台帳に記録 |
| 3 | `game-data/text/ja.json` | タイトル、メニュー、会話、警告文 | 文字が画面幅に収まる |
| 4 | `game-data/player.json` | 自機性能とショット | 初心者でも移動・被弾感が適切 |
| 5 | `game-data/bullets.json` | 弾の形、色、判定、速度 | 危険な弾と背景が識別できる |
| 6 | `game-data/enemies.json` | 敵性能、移動、使用弾幕 | HP・得点・接触判定が適切 |
| 7 | `game-data/patterns.json` | 弾幕の周期、角度、発射数 | 理不尽な初見被弾がない |
| 8 | `game-data/stages/` | 出現順、BGM、ボス、クリア条件 | ステージが最後まで進行する |

## 3. 画像・音声の差し替え

アセットはファイル名ではなく論理名で参照します。例えば `bgm_stage` はステージBGMという役割を表す名前であり、実際のファイルはマニフェストで指定します。この対応関係により、曲を差し替えてもステージ定義は変更不要です。

```json
{
  "assets": {
    "bgm_stage": "assets/audio/bgm/forest-stage.ogg",
    "se_shot": "assets/audio/se/player-shot.ogg"
  }
}
```

リリース候補の素材は、必ず次の項目を権利台帳に残します。

| 管理項目 | 記録例 |
|---|---|
| 論理名 | `bgm_stage` |
| ファイル | `assets/audio/bgm/forest-stage.ogg` |
| 制作者 | 制作者名または制作チーム名 |
| ライセンス | 自作、購入ライセンス、CC BYなど |
| 商用利用 | 可否と条件 |
| 再配布 | 可否と条件 |
| クレジット | 必要な表記 |
| 証跡 | 契約書、購入履歴、利用規約の保管先 |

## 4. 弾幕調整の基本

初心者向けの弾幕では、低速な弾、明確な隙間、発射直後の予備動作を意識します。扇状弾は `count` と `spread` を調整し、密度よりも弾の軌跡を読めることを優先します。円形弾は `count` を増やす前に `speed` を下げ、避けるための移動距離を確保します。

ボスの攻撃は、各フェーズに1つの理解しやすいテーマを持たせます。たとえば、「一定方向に回転する円形弾」「自機狙いの扇弾を小刻みに避ける」「低速の螺旋弾の隙間に入る」といったテーマです。色・弾形状・発射音を使い分け、攻撃の危険度をプレイヤーが予測できるようにします。

## 5. 新しい弾幕パターンが必要になった場合

既存の `fan`、`ring`、`aimed`、`spiral` の組み合わせで表現できる場合は、`patterns.json`だけを変更します。既存の表現では不足する場合に限り、新しいアクションを `PatternRunner`へ実装します。その際は、特定の作品固有名称をコードに入れず、他作品でも使える一般的な機能名とパラメータにします。

## 6. リリース前の最小確認

リリース候補では、タイトルから全ステージを開始し、ボス撃破・ゲームオーバー・コンティニュー・設定保存を確認します。すべてのアセットの権利台帳を確認し、開発用のダミー素材、デバッグ表示、未使用ファイル、権利が不明な素材を配布物から除外します。最後に、初見のテスターが操作説明なしでもショット・低速・ボムを理解できるかを確認します。
