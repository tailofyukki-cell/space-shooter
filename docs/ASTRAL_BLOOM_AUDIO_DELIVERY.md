# ASTRAL BLOOM — 第1ステージ音響実装報告

## 実装結果

第1ステージ「硝子雨の庭園」へ、通常BGM、ボスBGM、主要SEを統合した。BGMはステージ開始時とボス警告後のタイムライン切替に連動し、SEは自機ショット、敵弾発射、通常敵・ボス撃破、ボスフェーズ移行、被弾、グレイズ、ボムに対応する。

音声ファイルは外部の録音・サンプル・既存楽曲に依存しない手続き型生成で制作し、`scripts/generate_astral_audio.py` から再生成できる。配布用にはMP3へ変換し、ゲームパックのマニフェストから論理キーで参照する。別作品へ展開する際は同じキーへ別音源を割り当てれば、ゲームロジックを変更せずに音響を差し替えられる。

## BGM

| 論理キー | ファイル | 再生時間 | 内容 |
| --- | --- | ---: | --- |
| `bg_stage01` | `glassrain-garden.mp3` | 約89秒 | 132 BPM。青紫の軌道温室を進む通常ステージ向けの、透明感のあるベル・パッド・電子ドラムによるインストゥルメンタル。 |
| `bg_boss01` | `flora-orbis.mp3` | 約92秒 | 150 BPM。ボス戦の緊張感を強める、密度の高いアルペジオ・低域・電子ドラムによるインストゥルメンタル。 |

BGM切替には、旧曲の約260msフェードアウトと新曲の約420msフェードインを実装した。被弾時はBGMを一時的に下げ、約350ms後から復帰させる。

## SE

| 論理キー | ファイル | 再生時間 | 演出 |
| --- | --- | ---: | --- |
| `se_player_shot` | `cadenza-shot.mp3` | 約0.16秒 | 自機の光線ショット。 |
| `se_enemy_shot` | `petal-fire.mp3` | 約0.26秒 | 花弁・種子・蔓弾の発射。 |
| `se_enemy_destroy` | `crystal-break.mp3` | 約0.63秒 | 敵・結晶の破壊。 |
| `se_boss_phase` | `flora-phase.mp3` | 約0.99秒 | ボスのフェーズ移行と弾消去。 |
| `se_player_hit` | `player-hit.mp3` | 約0.47秒 | 被弾警告とBGMダッキング。 |
| `se_graze` | `graze.mp3` | 約0.13秒 | グレイズのきらめき。 |

連射による音の飽和を避けるため、自機ショット、敵弾、グレイズには45〜85msの再生クールダウンを適用した。

## 検証

| 検証項目 | 結果 |
| --- | --- |
| MP3形式・再生時間・ステレオ44.1kHz | 成功 |
| BGM・SEのラウドネス測定 | BGM平均 -17.3〜-16.5dB、主要SE平均 -9.5〜-8.1dB。イベント側音量倍率で弾幕中の聴感を調整。 |
| 音声アセット参照テスト | 成功。BGM2曲、SE7種を確認。 |
| 音声管理テスト | 成功。BGM開始・切替、SE音量、グレイズ間引き、被弾ダッキングを確認。 |
| ゲームワールド音声イベント | 成功。通常BGM、ボスBGM、自機ショット、敵弾、撃破、被弾を確認。 |
| Electron配布パッケージ | Linux AppImageのASARにゲームパック・BGM・SEが同梱されることを確認。 |

## 販売向けの扱い

BGM・SEの制作元、外部サンプル不使用、生成スクリプトを `THIRD_PARTY_NOTICES.md` に記録した。これによりR3（音声）の第1ステージ分は達成したが、販売候補全体としては複数ステージ、難易度、Windows実機QA、正式商品名・ストア素材・リリースビルドの固定が残っている。次の制作工程は、第2ステージの構成設計と、正式版の全体ボリューム確定である。
