# 横スクロール用ゲームパック仕様

## 座標系

プレイフィールドの原点は左上で、X軸は右方向、Y軸は下方向を正とする。角度は `0°` が右、`90°` が下、`180°` が左、`-90°` が上を表す。自機の通常ショットは原則 `0°`、敵弾の基本方向は `180°`、狙い撃ちは敵から自機への角度を使う。

## マニフェスト拡張

横スクロール作品のマニフェストでは、次を追加する。

```json
{
  "gameplay": {
    "scrollAxis": "horizontal",
    "playerSpawn": [118, 270],
    "cameraFlow": "rightToLeft"
  }
}
```

`display.fieldWidth` と `display.fieldHeight` は、横長のプレイ領域を表す。第1ステージでは `960×540` を標準とする。

## 自機定義

自機の `shots` と `focusShots` は、右向きの `angle: 0` を標準とする。左右移動はリスクと攻撃距離の選択として利用するため、X座標を画面左側の一定範囲に制限する。

## 敵定義

| 移動 | 主要値 | 横スクロールでの役割 |
| --- | --- | --- |
| `line` | `velocity: [-x, 0]` | 右から左へ通過する小型敵。 |
| `sine` | `velocity: [-x, 0]`、`amplitude`、`frequency` | 上下へ蛇行する花弁精霊。 |
| `hover` | `target: [x, y]` | 画面右寄りで攻撃する中型敵・ボス。 |

敵の出現位置は原則として `fieldWidth + 40` 以上とし、正面から接近させる。ボスはプレイ領域右寄りのターゲット座標まで移動後に弾幕を開始する。

## 弾幕定義

既存の `fan`、`ring`、`aimed`、`spiral` をそのまま利用する。ただし、発射角度を横スクロール向けにする。

| パターン | 基本方向 | プレイ上の狙い |
| --- | --- | --- |
| 花粉扇状弾 | `180°` | 左へ広がる基本弾。上下の隙間を作る。 |
| 花弁円形弾 | `0°` を基準に全方向 | 画面内に一時的な障害を作り、前後移動を促す。 |
| 種子狙い撃ち | `aimAtPlayer: true` | 自機位置へ収束する短い弾列。 |
| 蔓螺旋弾 | `180°` を基準 | 右側から左へ伸びる緩い螺旋。 |

## ステージタイムライン

第1ステージは以下の区間で構成する。

| 時刻 | 区間 | 出現 |
| ---: | --- | --- |
| 0〜10秒 | 軌道温室への接近 | 花粉偵察機3機。 |
| 10〜26秒 | 花弁回廊 | 花弁精霊と花粉偵察機。 |
| 26〜52秒 | 結晶温室 | 結晶ガーデナーと護衛。 |
| 52秒〜 | 庭園制御核戦 | フローラ・オルビスの2フェーズ。 |

## 互換性

ゲームパックは `gameplay.scrollAxis` を必須とし、ランタイムは `horizontal` と `vertical` を明確に分岐する。標準の起動設定は `horizontal` のASTRAL BLOOMパックへ変更する。既存の縦型パックは参照用として別IDに保全し、通常のステージ選択・公開対象には含めない。
