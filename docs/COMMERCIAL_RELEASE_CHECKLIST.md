# 同人ゲーム販売リリース・チェックリスト

## 目的

この文書は、Danmaku Engine Demo を作品固有の弾幕シューティングとして販売する際に、リリース候補を判定するための実務チェックリストです。エンジンの完了と、商品としての完成は別の工程です。各作品について、以下の確認を証跡付きで実施してください。

## リリースゲート

| ゲート | 合格条件 | 証跡 |
| --- | --- | --- |
| G1: コンテンツ固定 | ステージ、敵、弾幕、文言、アセットのバージョンが固定されている。 | Gitタグ、ゲームパック差分、アセット一覧 |
| G2: 権利確認 | 全素材について商用利用可否、必要表記、配布制限を確認済みである。 | `THIRD_PARTY_NOTICES.md`、購入・利用記録 |
| G3: 機能テスト | 起動、入力、ポーズ、設定保存、クリア、ゲームオーバー、リトライを確認済みである。 | テスト記録、動画、Issue一覧 |
| G4: 実機テスト | 対象Windows環境でインストール、起動、終了、アンインストールを確認済みである。 | OS・GPU・入力機器別テスト表 |
| G5: ストア準備 | 商品説明、年齢区分、価格、スクリーンショット、サポート窓口、既知の不具合を準備済みである。 | ストア下書き、画像一式 |
| G6: 配布固定 | インストーラー、ポータブル版、ハッシュ、変更履歴を固定している。 | GitHub Release／配布ページ、SHA-256一覧 |

## 作品パックの固定手順

販売候補を作る際は、まず `game-data/` と `assets/` を作品専用の状態へ固定します。`manifest.json` の `id` は公開後に安易に変更しないでください。設定保存のキーに利用されるため、アップデート後に変えるとプレイヤーの音量・キー設定が分断されます。

各ステージについて、Normal相当の想定ルートでクリア可能であること、被弾時の無敵時間とボム発動が期待どおりであること、スコアが負値やNaNにならないことを確認します。ボス撃破、時間切れ、残機切れ、ポーズ中の入力、設定画面を経由した再開を含めて、最低1回は通しで試遊してください。

## Windows配布工程

Windows向けリリース候補は、Windowsランナー上で `pnpm run build:win` を実行して生成します。Electronのアプリケーション配布では、アプリとランタイムを同梱したパッケージを作成します。[1] `electron-builder` はWindows用にNSIS、ポータブルなどの出力ターゲットを提供しています。[2]

本リポジトリでは、`.github/workflows/windows-release.yml` がWindows x64のNSISインストーラーとポータブル版を生成します。タグを付与する前に、ローカルで `pnpm run check`、`pnpm run test:smoke`、`pnpm run test:settings` を実行し、GitHub Actionsで同じ検証が通ることを確認します。

```bash
# リリース候補の事前検証
pnpm run check
pnpm run test:smoke
pnpm run test:settings

# Windowsのネイティブ環境で実行
pnpm run build:win
```

Windows実行ファイルを一般向けに継続配布する場合は、署名証明書を取得し、署名済みの最終成果物を採用する方針を決めてください。electron-builderのWindows設定では、署名情報を設定して各実行ファイル・インストーラーへ署名できます。[3]

## 配布ファイルの固定

GitHub Actionsから得た成果物をダウンロードしたら、SHA-256ハッシュを作成し、配布ページまたは同梱の `CHECKSUMS.txt` に掲載します。ハッシュの確認手順も購入者向けREADMEへ記載してください。

```bash
sha256sum "Danmaku Engine Demo-<version>-win-x64-setup.exe" \
          "Danmaku Engine Demo-<version>-win-x64-portable.exe" \
          > CHECKSUMS.txt
```

## 販売ページに必要な素材

販売ページは、ゲームの世界観と購入後に得られる体験を明確に伝える必要があります。作品名、ジャンル、対応OS、対応言語、入力方式、プレイ人数、想定プレイ時間、既知の制限、更新方針、連絡先を明記してください。スクリーンショットはタイトル、プレイ画面、ボス戦、設定画面など、実際のゲーム内容が分かる構成にします。

商品の説明文、画像、音声、体験版、アップデート内容は、使用する販売プラットフォームの審査・表記・年齢区分ガイドラインに合わせて最終確認してください。プラットフォームごとの条件は変更され得るため、公開直前に公式ガイドラインを再確認する運用を推奨します。

## 未完了として扱う事項

この基盤だけでは、作品固有のアート、BGM、SE、複数難易度、ストーリー、実機互換性試験、ストア登録、コード署名は完了しません。これらを完了しない限り、「販売可能な商品」ではなく「販売準備を進められる技術基盤」として扱ってください。
