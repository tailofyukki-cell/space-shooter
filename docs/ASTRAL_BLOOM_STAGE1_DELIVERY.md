# ASTRAL BLOOM — 第1ステージ実装報告

**対象作品:** ASTRAL BLOOM — 星環のカデンツァ  
**対象ステージ:** STAGE 01 — 硝子雨の庭園  
**実装状態:** 試遊可能な初期プロトタイプ

## 概要

検証用のゲームパックを保全したうえで、新作ゲームパック `content-packs/astral-bloom/` を作成した。起動時は `content-packs/active-pack.json` を通じて有効パックを選択し、現在はASTRAL BLOOMが読み込まれる。デモへ戻したい場合は、同ファイルの `active` を `demo-engine` に変更するだけでよい。

ASTRAL BLOOMでは、軌道庭園「硝子雨の庭園」に侵入した自機〈カデンツァ7〉が、暴走した庭園制御核〈フローラ・オルビス〉を停止する。タイトル、ステージ選択、開始アナウンス、HUD、結果画面に用いる主要文言を作品固有の内容へ置き換えた。

## 実装済みコンテンツ

| 区分 | 実装内容 |
| --- | --- |
| 自機 | 軌道保安機〈カデンツァ7〉。通常時は2連ショット、低速時は3連の収束ショット。残機3、ボム3。 |
| 通常敵 | 花粉偵察機、花弁精霊、結晶ガーデナー。直進、蛇行、滞在の3種の移動を使用。 |
| ボス | フローラ・オルビス。花冠の観測者、硝子雨の心臓の2フェーズ。フェーズ移行時には旧弾を消去し、新しい弾幕へ切り替える。 |
| 敵弾 | 花弁弾、種子弾、蔓針、制御核弾。危険弾はマゼンタ〜珊瑚色、自弾は青緑〜白で視認性を分離。 |
| 弾幕 | 扇状、円形、狙い撃ち、螺旋。各敵の役割に合わせてJSONで定義。 |
| ステージ進行 | 導入、花弁回廊、結晶温室、ボス戦をタイムラインで定義。 |

## 初期難易度調整

第1ステージ前半を固定デルタタイムで自動試遊した。初期値では約19秒でゲームオーバーとなったため、花粉偵察機の扇状弾を5way×5回から3way×3回へ、花弁精霊の円形弾を12way×4回から8way×3回へ減らした。結晶ガーデナーの狙い撃ちと螺旋も発射周期を延長し、弾速を下げている。

調整後の回避行動付き自動試遊では、52秒間ゲームオーバーにならず、最大同時敵弾数は43、残機1、獲得スコア1,820となった。初見プレイとしてはなお緊張感のある水準であるため、実機試遊を通じてさらに弾速、残機、ボム補充、背景と弾の視認性を調整する。

## 次の制作順

1. 自機〈カデンツァ7〉、3種の通常敵、ボス〈フローラ・オルビス〉、硝子雨の庭園背景の実アセットを制作する。
2. BGM2曲とSEを制作・選定し、`manifest.json` の論理名へ配置する。
3. ボス戦を実機で試遊し、フェーズ間の難易度曲線とボム使用機会を調整する。
4. 第2ステージと難易度選択を追加し、作品全体のプレイ時間と物語を設計する。
5. Windowsデスクトップ版で連続試遊・ゲームパッド試験を実施する。
