# ASTRAL BLOOM — 自動キャンペーン進行 実装報告

## 実装内容

通常ステージの最終ボスを撃破すると、結果画面へ戻らずに次のキャンペーンステージへ自動進行するよう変更した。第1から第3ステージのクリア後は2.6秒間の到達通知を表示し、その後、次ステージを開始する。第4ステージだけはキャンペーン終端としてエンディングへ遷移する。

| クリアしたステージ | 遷移先 | 結果 |
| --- | --- | --- |
| STAGE 01 — 硝子雨の庭園 | STAGE 02 — 月虹の導水路 | 自動進行 |
| STAGE 02 — 月虹の導水路 | STAGE 03 — 星蝕の外環樹海 | 自動進行 |
| STAGE 03 — 星蝕の外環樹海 | STAGE 04 — アストラル・ブルーム中枢 | 自動進行 |
| STAGE 04 — アストラル・ブルーム中枢 | エンディング | 最終クリア |

## 状態維持

自動進行では、選択済み難易度、スコア、残機、ボム、グレイズを引き継ぐ。次ステージは自機の開始位置から再開し、2.25秒の入場無敵を付与する。敵、敵弾、パターン実行状態はクリアして、前ステージの弾幕が次ステージへ持ち越されないようにした。

新規出撃、リトライ、タイトルからの開始では従来どおり難易度に応じた初期残機・ボム、スコア0へ初期化される。

## 表示導線

ステージクリア後は、通知バナーに次の2行を表示する。

> STAGE CLEAR // クリアしたステージ名
> NEXT MISSION // 次ステージ名 — 英語副題

この待機中は固定ステージHUDも `NEXT MISSION` に切り替わり、次に始まるマップの和名・副題・進行バーを表示する。ステージ開始後は従来の `MISSION PROGRESS` 表示へ戻る。

## 検証

専用の `campaign-transition.test.js` で、第1ステージから第2ステージへの遷移予約、状態維持、次ステージの安全な開始、通常の新規出撃時の初期化を検証した。さらに、構文、エンディング分岐、常時HUD、4ステージのスモーク、中ボス、難易度、設定、音声、自動試遊の回帰テストを実行して成功した。
