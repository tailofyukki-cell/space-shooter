# ASTRAL BLOOM — 第1ステージ実アート統合報告

## 実施内容

横スクロール版ASTRAL BLOOMの第1ステージ「硝子雨の庭園」へ、差し替え可能な実アートアセットを統合した。これまでのCanvas図形描画を削除せず、画像が利用可能な場合は作品固有アートを描画し、画像の欠落や読込失敗時には従来の図形描画へ戻る構成である。

ゲームパックの `manifest.json` に `visuals` セクションを追加し、背景、自機、通常敵3種、ボスの各論理キーとファイルパスを分離した。したがって、別作品を制作する際は同じキーに別の画像を指定することで、ゲームロジックを変更せずアートだけを置き換えられる。

## 描画上の判断

背景は生成画像の端部が完全には接続しないため、背景画像を二重に横移動させる方式は採用しなかった。背景そのものは静止配置し、星レイヤーを右から左へ流すことで横スクロールの移動感を維持している。これにより、背景の縦方向の継ぎ目が弾幕の回避判断を妨げる問題を回避した。

アセット容量は、生成時の中間画像を除外してゲーム用最適化素材だけを残すことで、合計約1.3MBへ抑えた。背景は1920×1080から最適化JPEGへ変換し、ゲーム内で必要な品質と読込効率の両方を確保している。
