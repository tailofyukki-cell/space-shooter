# ASTRAL BLOOM — 横スクロール復元報告

## 結論

ASTRAL BLOOMの標準プロトタイプを、元MVPと同じ**横スクロール2Dシューティング**へ復元した。自機は横長のプレイ領域左側から右を向き、背景は右から左へ流れる。敵は右側から接近し、自機ショットは右へ、敵弾は左または自機へ向かう。

縦型プロトタイプを削除せず、`content-packs/astral-bloom-vertical-reference/` に参照用として保存した。通常起動で読み込まれる `content-packs/astral-bloom/` は横スクロール版である。

## 変更内容

| 項目 | 横スクロール版での内容 |
| --- | --- |
| プレイフィールド | 960×540の横長領域を中央配置。 |
| 自機 | 左側の `[118, 270]` から開始し、右向きに描画・ショットする。 |
| 背景 | 星が右から左へ流れる。 |
| 敵移動 | 花粉偵察機は左進、花弁精霊は上下に蛇行しながら左進、ボスは右寄りへ停滞する。 |
| 弾幕 | 扇状弾・種子弾・蔓弾の基準方向を左向きへ変更。狙い撃ちは自機方向を使う。 |
| 作品データ | `gameplay.scrollAxis: horizontal` をマニフェストへ追加。 |
| 既存機能 | JSONゲームパック、ボス2フェーズ、設定、音声フック、Electron配布、テストは継承。 |

## ローカル試遊

ローカルフォルダは `C:\Users\konkon\Downloads\GitHub\Manusgame\shoot\1st` である。ローカルサーバーから取得したマニフェストは `scrollAxis: horizontal` と `0.2.0-horizontal-prototype` を返した。

ブラウザで `http://127.0.0.1:4173/` を開けば、横スクロール版を試遊できる。サーバーを再起動する場合は、同フォルダで次を実行する。

```bat
py -3 -m http.server 4173 --bind 127.0.0.1
```
