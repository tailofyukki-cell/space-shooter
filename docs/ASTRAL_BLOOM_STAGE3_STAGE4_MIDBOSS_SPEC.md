# ASTRAL BLOOM — 第3・第4ステージと中ボス仕様

## 目的

本仕様は、既存の第1・第2ステージに続く第3・第4ステージを追加し、通常敵と最終ボスの間に明確な戦闘の山場を作る中ボスを導入するためのものである。第4ステージをキャンペーン終端とし、既存のエンディングは第4ステージの最終ボス撃破後にのみ到達する。

## キャンペーン構成

| 順序 | ステージ | 舞台と弾幕テーマ | 中ボス | 最終ボス |
| ---: | --- | --- | --- | --- |
| 1 | 硝子雨の庭園 | 桃・青紫の花弁、種子、蔓 | なし | フローラ・オルビス |
| 2 | 月虹の導水路 | 琥珀プリズム、水門針、潮流 | なし | ルーメン・アーコン |
| 3 | 星蝕の外環樹海 | 黄緑の太陽葉、琥珀コロナ、回転する枝刃 | テッサ・リーヴ | アウレア・エクリプス |
| 4 | アストラル・ブルーム中枢 | 白紫の星核、分光花弁、収束レーンクリスタル | ノクス・リーヴ | ガーデン・ハート |

第3ステージは視認性の高い黄緑・琥珀の弾幕を使い、横方向から迫るコロナ状の配置を主題とする。第4ステージは白紫・群青を主色とし、プレイヤーの上下移動を要求する分光弾幕を使う。

## 中ボスの共通契約

中ボスは敵定義の `kind: "midboss"` を使用する。中ボスは通常敵より大きいHPゲージとフェーズを持ち、画面右側の所定位置までホバー移動した後に弾幕を開始する。一方、`kind: "boss"` のみをステージクリア条件の最終ボスとし、中ボス撃破はステージクリアを直接発火させない。

中ボスは次の共通仕様を持つ。

| 項目 | 仕様 |
| --- | --- |
| フェーズ | 2フェーズ。遷移時に敵弾を消去し、新しい弾幕を開始する。 |
| HPゲージ | 通常敵より優先して表示し、`SUB BOSS`を識別表示する。 |
| ボム | 通常敵のように即時浄化されず、最終ボスと同様に小ダメージを受ける。 |
| 撃破 | 敵弾全消去、強い爆発、加点、撃破SEを実行する。 |
| バリエーション | 外装色、移動位置、フェーズ弾幕、HP、出現ステージをデータだけで差し替える。 |

## 中ボスバリエーション

| ID | 名称 | 出現 | シルエット | 弾幕 |
| --- | --- | --- | --- | --- |
| `tessa_reave` | 冠鎌機テッサ・リーヴ | 第3ステージ | 黄緑の花冠と二対の剪定鎌 | コロナ扇、枝刃螺旋 |
| `nox_reave` | 深層接続機ノクス・リーヴ | 第4ステージ | 群青の星核と三対の接続アーム | 分光環、星核狙い撃ち |

## 第3・第4ステージのデータ方針

各ステージは既存のタイムラインJSONを使い、`midboss`イベントで中ボスを出現させる。背景画像・中ボス画像・最終ボス画像はマニフェストの `visuals.backgrounds` と `visuals.sprites` に登録する。BGMは現段階では既存の通常・ボスBGMを再利用し、販売候補化の音楽制作工程で第3・第4ステージ専用曲へ置き換える。

## エンディング条件

キャンペーン終端はマニフェストのステージ配列の最後の要素とする。第4ステージを最後に追加することで、既存の終端判定処理は変更せずにエンディング到達条件を第4ステージへ移せる。
