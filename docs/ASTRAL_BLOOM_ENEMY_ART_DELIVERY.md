# ASTRAL BLOOM — 敵アート刷新報告

## 実装結果

第1ステージの通常敵3種とボス〈フローラ・オルビス〉を、仮の図形フォールバックに見えない機械花・結晶系の実アートへ刷新した。小型の花粉偵察機、蛇行する花弁精霊、重装の結晶ガーデナー、六枚の装甲花弁と深紅の結晶核を持つフローラ・オルビスを、左向きの横スクロール用シルエットとして整形している。

あわせて、敵エンティティの一意ID（例：`pollen_scout:7`）をそのまま画像キーとして使っていた不具合を修正した。敵種別ID（例：`pollen_scout`）を別に保持し、レンダラーがマニフェストの `sprite:pollen_scout` を参照するようになったため、通常敵・ボスともに図形フォールバックではなく実スプライトを描画する。

## アート内容

| 敵 | 主な識別要素 | 表示サイズ |
| --- | --- | ---: |
| 花粉偵察機 | 黄緑の単眼、三枚の黒紫機械花弁翼、左向きの迎撃胴体 | 64×48 px |
| 花弁精霊 | 青緑の硝子核、五枚の刃状花弁、機械蔓 | 82×64 px |
| 結晶ガーデナー | 深緑の六角温室、剪定アーム、黒曜石装甲 | 112×90 px |
| フローラ・オルビス | 深紅の結晶核、六枚の装甲花弁、硝子軌道リング、左向き前部 | 230×182 px |

敵本体は黒紫・白銀・青緑・深緑を中心にし、危険弾のマゼンタ・珊瑚色と混同しないよう設計した。元画像の一時クロマ背景は除去し、最終ゲーム用PNGは透明背景・最適化済みである。

## 検証

| 検証項目 | 結果 |

## 販売向けの扱い

ゲーム用PNGのみを配布対象として残し、約33MBの高解像度中間画像を除外した。最終スプライト群は合計約676KBであり、配布物の容量を不要に増やさない。生成・整形に関する記録と、販売前に確認すべき画像生成サービスの利用条件は `THIRD_PARTY_NOTICES.md` に記録した。

次の視覚品質向上では、敵の移動アニメーション、被弾時の発光、撃破時の花弁破片、ボスフェーズ別の色変化を実装する。これにより、静止スプライトから販売作品らしい戦闘表現へ進められる。
